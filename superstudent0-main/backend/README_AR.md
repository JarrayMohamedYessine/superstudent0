# السحابة المجانية لـ SuperStudent (Python Worker)

**Cloudflare (كاش + ملفات ثابتة) + Telegram (الخزنة الدائمة) + Catbox (الملفات)** — بلا KV وبلا أي قاعدة بيانات.

## أين يُحفظ كل شيء
| ماذا | أين | يُقرأ من | الكاش |
|---|---|---|---|
| PDF والصور | Catbox (روابط دائمة) | الرابط، أو `/api/file?u=` | يوم |
| بنك الأرشيف | Telegram + **10 ملفات** `archive-bank.0..9.json` | ملفات الموقع (بلا Worker) | أسبوع |
| الإعلانات | Telegram + **ملفان** `ads.0/1.json` | ملفات الموقع | أسبوع |
| الأسئلة الشائعة | Telegram + **ملف** `faqs.json` | ملفات الموقع | أسبوع |
| إعلانات الصفحة الرئيسية، الإعلانات الفائقة، قصص النجاح | Telegram + **ملف** `content.json` | ملفات الموقع | أسبوع |
| الأشخاص (اسم، صورة، شعبة، رتبة) | Telegram + `people.0.json`… | ملفات الموقع | أسبوع |
| **البريد وكلمة السر** | Telegram فقط (سلال خاصة) | Telegram | يوم |
| **الطلبات** (انضمام، ملاحظات، شكاوى، تذاكر) | Telegram فقط | Telegram للمشرفين فقط | — |
| المؤشرات (أرقام الرسائل) | رسالة «head» مثبّتة في القناة | القناة | 30 ثانية |

- **حد 20 ملفاً**: 14 نصاً + manifest = 15، وتبقى **5 ملفات للأشخاص**. عند وصول ملف الأشخاص إلى 100 ألف يُنشأ التالي تلقائياً أثناء المزامنة. السعة = **500 ألف شخص**؛ عند الامتلاء يُرفض التسجيل برسالة واضحة (لا يتجاوز الموقع 20 ملفاً أبداً، والاختبارات تضمن ذلك).
- **الطلبات ليست في ملف عام** عمداً: تحوي بريد المترشحين وحساب Discord وصورة الإثبات، وأي ملف في الموقع يقرؤه كل زائر.
- لتغيير توزيع الملفات: `REGISTRY` في `backend/src/ss/texts.py` (المجموع محروس بالاختبارات).

## الإعداد (مرة واحدة)
1. **Telegram**: بوت من @BotFather + قناة **خاصة** + البوت مشرف فيها بصلاحيتي **النشر** و**تثبيت الرسائل**، ثم رقم القناة (`-100…`).
2. **الأسرار** (من `backend/`، بالأمر `npx wrangler secret put NAME`):
   `TELEGRAM_BOT_TOKEN` · `TELEGRAM_CHAT_ID` · `JWT_SECRET` (32+) · `PEPPER` (32+) · `EXPORT_TOKEN` (24+) · `OWNER_EMAIL` (بريدك: يصبح المشرف الأعلى).
3. **النشر**: `cd backend && uv run pywrangler deploy` (Worker جديد باسم `archive-platform-py` بجانب القديم، لا شيء يُستبدل).
4. **نطاق خاص (Custom Domain)** — لازم ليعمل الكاش: Cache API لا يعمل على `workers.dev`. بدونه يعمل كل شيء لكن بلا كاش (أبطأ وأثقل على Telegram).
5. **المزامنة**: أضف في GitHub السرّين `SS_API_URL` و`SS_EXPORT_TOKEN` وشغّل *Sync store snapshot* (يعمل لاحقاً كل 3 ساعات). حماية: لا يستبدل ملفاً فيه بيانات بملف فارغ، ولا يسمح بتقلّص أكثر من النصف، ولا يتجاوز 20 ملفاً، ولا يؤكّد استلام الأشخاص إلا بعد نجاح الـ push.

## ⚠️ مهم
- **لا تضع** `VITE_TELEGRAM_BOT_TOKEN` في إعدادات البناء: كل متغير `VITE_` يُدمج في جافاسكربت يقرؤه أي زائر.
- الكود القديم كان يرسل كلمات السر نصاً صريحاً إلى Telegram؛ الجديد يحفظ **تجزئة** فقط (PBKDF2 + ملح + pepper).

## الحدود الحقيقية
- **Worker مجاني**: 100,000 طلب/يوم لـ `/api/*` فقط (الملفات الثابتة بلا حد)، و10ms وحدة معالجة لكل طلب.
- **Telegram**: رسالة واحدة/ثانية تقريباً للقناة. كل كتابة = 3–4 رسائل، والكثافة العالية تُرجع 503 مع `Retry-After`.
- **التفرّد**: بلا قاعدة بيانات، إن سجّل شخصان بنفس الاسم في اللحظة نفسها قد ينجح أحدهما ويُعاد الآخر؛ تُكتشف معظم الحالات (الكتابة تُعاد على الرأس الأحدث) لكنه ليس ضماناً 100%.
- **ظهور الجديد**: النصوص/الأشخاص الجدد تظهر لبقية الزوار بعد المزامنة (حتى 3 ساعات). تسجيل الدخول لا ينتظر المزامنة.
- **رفع الملفات**: حتى 50MB، يُمرَّر مباشرة إلى Catbox.
- **غير مختبر على Cloudflare الحقيقي**: `src/entry.py` وحده يلمس بيئته؛ كل ما عداه (72 اختباراً) بنسخ وهمية. إن ظهر خطأ CPU عند الدخول فاضبط `PBKDF2_ITERATIONS` (مثلاً 50000)؛ كل تجزئة تحمل عدد جولاتها فلا يتأثر أي حساب موجود.
