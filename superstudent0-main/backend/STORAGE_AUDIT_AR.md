# جرد التخزين: كل نوع بيانات في الكود وأين يذهب

✅ موصول وجاهز · 🟡 موصول جزئياً · ⚪ لا يحتاج سحابة · ❌ بلا تخزين سحابي بعد

| البيانات (المفتاح في الكود) | التخزين الآن | الحالة |
|---|---|---|
| الحسابات، البريد، كلمة السر (`account:`, `usernameIndex:`, `session`) | Telegram فقط (سلال خاصة) + جلسة JWT | ✅ |
| دخول سريع بالكود (`accessCodeIndex:`) | محلي فقط، الخادم لا يدعمه | ❌ |
| صلاحيات الإدارة (ترقية، حظر، رفع، حذف حساب) | تُرسل للخادم عبر `/api/admin/*` | ✅ |
| قائمة الحظر | Telegram (خاص) | ✅ |
| بنك الأرشيف (نصوص الوثائق وروابطها) | Telegram + 10 ملفات موقع | ✅ |
| ملفات PDF | Catbox (رابط دائم) + كاش يوم | ✅ |
| `pdf:` و`doc_meta:` | نسخة محلية في متصفح كل جهاز (احتياط) | ⚪ |
| صور الصور الشخصية والإثبات | Catbox، والرابط فقط يُحفظ | ✅ (تتطلب جلسة خادم) |
| الأشخاص (اسم، صورة، شعبة، رتبة) | Telegram + `people.N.json` (ملف جديد كل 100 ألف) | 🟡 يُكتب، والواجهة لا تقرؤه بعد |
| طلبات الانضمام (`elite_applications:all`) | Telegram خاص، للمشرفين | ✅ |
| ملفات المتقدمين (`dev:applicant:`) | محلي فقط (نفس معلومات الطلب) | ❌ |
| الملاحظات (`student_feedbacks:all`) | Telegram خاص | ✅ |
| الشكاوى (`complaint_reports:all`) | Telegram خاص | ✅ |
| تذاكر التواصل (`contact_tickets`) | Telegram خاص | ✅ |
| الأسئلة الشائعة (`faqs:dynamic_list`) | Telegram + `faqs.json` | ✅ |
| إعلانات الصفحة الرئيسية والإعلانات الفائقة | Telegram + `content.json` | ✅ (غير المشرف يُنشئ ولا يعدّل) |
| قصص النجاح (`success_stories`) | Telegram + `content.json` | ✅ |
| الإعلانات التجارية (ملفان `ads.0/1.json`) | المجموعة جاهزة في الخلفية | ❌ لا توجد شاشة في الواجهة تعرضها (`public/data/ads.json` لا يقرؤه أي كود) |
| استطلاع الشهر (`current_monthly_poll`) | محلي فقط | ❌ (كل صوت = كتابة؛ يلزم عدّاد، لا يناسب Telegram) |
| غرف الدردشة (`room_msgs_`, `room:`) و`chat_media_vault` | لا شاشة تستعملها (كود ميّت)، الدردشة عبر Discord | ⚪ |
| `presence-registry`, `ai_reactions_log`, `bac_ai_cache_`, `lang-pref`, `dismissed_ann_`, `bac_anon_voter_id` | تفضيلات وإحصاءات لكل جهاز | ⚪ |
